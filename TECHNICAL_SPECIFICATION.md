# Техническое задание (ТЗ)
## Мод системы голосовой озвучки для игры "The Coffin of Andy and Leyley"

---

### 1. Общие сведения

**Наименование проекта:** Мод голосовой озвучки для The Coffin of Andy and Leyley  
**Версия документа:** 1.0  
**Дата создания:** 2024  
**Платформа:** Godot Engine 4.x  
**Язык разработки:** GDScript  

---

### 2. Назначение и цели проекта

#### 2.1. Назначение
Мод предназначен для добавления системы воспроизведения голосовой озвучки диалогов в игре The Coffin of Andy and Leyley. Система поддерживает автоматическую интеграцию с русификаторами формата `.cld`.

#### 2.2. Цели
- Автоматическое воспроизведение аудиофайлов при отображении текста диалога
- Интеграция с файлами русификатора для автоматического определения имён файлов озвучки
- Поддержка различных форматов аудио (FLAC, OGG, WAV, MP3)
- Минимальное влияние на производительность игры
- Гибкая настройка поведения системы

### 3. Требования к функциональности

#### 3.1. Основные функции

##### 3.1.1. Управление воспроизведением аудио
**VoiceManager.gd** (основной менеджер):
- Воспроизведение аудиофайлов по имени
- Очередь воспроизведения (режимы: immediate, wait, queue)
- Кэширование загруженных аудио потоков
- Контроль громкости (регулировка в dB)
- Сигналы начала и окончания воспроизведения

##### 3.1.2. Интеграция с русификатором
- Автоматическая загрузка файла `Русский.cld` из папки `voice_mod/languages/`
- Парсинг JSON-структуры русификатора
- Поиск русского текста реплики по ID
- Преобразование текста в имя файла (транслитерация кириллицы)
- Работа без русификатора (не ломается при отсутствии файла)

##### 3.1.3. Система таймкодов
**VoiceTimingManager.gd**:
- Автоматическое сканирование папки `voice_mod/audio/` при первом запуске
- Измерение длительности каждого аудиофайла
- Сохранение результатов в кэш-файл `user://voice_timing_cache.json`
- Мгновенная загрузка кэша при повторных запусках
- Экспорт таймкодов в CSV формат
- Сигналы начала и завершения сканирования

##### 3.1.4. Интеграция с диалоговой системой
**DialogueVoiceIntegration.gd**:
- Автоматический поиск узлов текста диалога и спикера
- Привязка к сигналам диалоговой системы
- Воспроизведение озвучки при показе реплики
- Поддержка передачи ID реплики для поиска в русификаторе

##### 3.1.5. Экран загрузки
**VoiceLoadingScreen.gd**:
- Отображение прогресс-бара при сканировании аудиофайлов
- Показ текущего обрабатываемого файла
- Отображение статистики (количество файлов, общая длительность)
- Автоматическое скрытие после завершения сканирования

#### 3.2. Дополнительные функции

##### 3.2.1. Установщик озвучки
**VoiceInstaller.gd** + **Installer.tscn**:
- Сканирование проекта в поисках аудиофайлов
- Парсинг имён файлов формата `ID_Персонаж.ext` или `Персонаж_ID.ext`
- Распределение файлов по папкам `voice_mod/audio/<персонаж>/`
- Поэтапная обработка без зависания интерфейса
- Автоматический запуск генерации кэша таймкодов

##### 3.2.2. Конфигурация
**voice_settings.ini**:
- Включение/выключение озвучки
- Настройка громкости
- Выбор режима воспроизведения
- Настройка поведения при клике
- Включение/выключение логирования

### 5. Технические требования

#### 5.1. Требования к среде выполнения
- **Движок:** Godot Engine 4.0 или выше
- **ОС:** Windows, Linux, macOS (кроссплатформенность Godot)
- **Память:** Зависит от размера аудиофайлов (рекомендуется кэширование)

#### 5.2. Поддерживаемые форматы аудио
- `.flac` — рекомендуется (без потерь, хорошее сжатие)
- `.ogg` — для длинных файлов
- `.wav` — без сжатия
- `.mp3` — максимальное сжатие

#### 5.3. Требования к структуре файлов
- Имена файлов должны содержать подчёркивание `_` как разделитель
- Формат: `{ID}_{Персонаж}.ext` или `{Персонаж}_{ID}.ext`
- Регистр символов важен (чувствительно к регистру)
- Поддержка транслитерации кириллических имён персонажей

#### 5.4. Производительность
- Асинхронное сканирование файлов без блокировки UI
- Кэширование таймкодов для мгновенной загрузки
- Пакетная обработка файлов установщиком (0.05 сек на файл)

### 6. Интерфейсы и интеграция

#### 6.1. API VoiceManager

**Основные методы:**
```gdscript
play_voice(file_name: String)                    # Воспроизвести файл
play_voice_immediate(file_name: String)          # Воспроизвести немедленно
stop()                                           # Остановить воспроизведение
set_volume(volume_db: float)                     # Установить громкость
is_playing() -> bool                             # Проверка воспроизведения
get_current_file() -> String                     # Получить текущий файл
get_russian_text(line_id: String) -> String      # Получить текст из русификатора
get_voice_file_for_russian_line(id, speaker)     # Получить имя файла озвучки
is_rusifier_loaded() -> bool                     # Проверка загрузки русификатора
```

**Сигналы:**
```gdscript
voice_started(file_name: String)    # Начало воспроизведения
voice_finished()                    # Окончание воспроизведения
```

#### 6.2. API VoiceTimingManager

**Основные методы:**
```gdscript
scan_all_audio_files()                      # Сканировать все файлы
get_timing_for_file(filename: String)       # Получить длительность файла
get_voice_duration_for_line(id, speaker)    # Длительность для реплики
export_timing_to_csv(path: String)          # Экспорт в CSV
```

**Сигналы:**
```gdscript
timing_scan_started()              # Начало сканирования
timing_scan_finished(total: int)   # Завершение сканирования
```

#### 6.3. API DialogueVoiceIntegration

**Основные методы:**
```gdscript
setup_voice_integration(root, dialogue_path, text_path, speaker_path)
show_dialogue(text: String, speaker: String, line_id: String = "")
```

### 7. Сценарии использования

#### 7.1. Установка мода

1. Скопировать папку `voice_mod/` в корень проекта игры
2. Добавить autoload в Project Settings:
   - `VoiceManager.gd` → `VoiceManager`
   - `VoiceTimingManager.gd` → `VoiceTimingManager`
   - `DialogueVoiceIntegration.gd` → `DialogueVoice` (опционально)
3. Поместить файл русификатора `Русский.cld` в `voice_mod/languages/`
4. Добавить аудиофайлы в `voice_mod/audio/`

#### 7.2. Использование установщика

1. Поместить файлы озвучки в корень проекта (рядом с `project.godot`)
2. Открыть сцену `InstallerScene/Installer.tscn`
3. Запустить сцену (F5)
4. Дождаться завершения распределения файлов
5. Запустить основную игру

#### 7.3. Интеграция с диалогами

**Вариант A — Автоматическая интеграция:**
```gdscript
func _ready():
    DialogueVoice.setup_voice_integration(
        get_tree().root,
        ^"Path/To/DialogueNode",
        ^"Path/To/TextLabel",
        ^"Path/To/SpeakerLabel"
    )

func show_next_line():
    var line_data = get_current_line()
    DialogueVoice.show_dialogue(
        line_data.text,
        line_data.speaker,
        line_data.id  # ID для поиска в русификаторе
    )
```

**Вариант B — Ручной вызов:**
```gdscript
func show_dialogue(text: String, speaker: String, line_id: String = ""):
    dialogue_label.text = text
    speaker_label.text = speaker
    
    if VoiceManager:
        if not line_id.is_empty():
            var filename = VoiceManager.get_voice_file_for_russian_line(line_id, speaker)
            if not filename.is_empty():
                VoiceManager.play_voice(filename)
```

### 8. Обработка ошибок

#### 8.1. Типовые ситуации

| Ситуация | Поведение системы |
|----------|------------------|
| Файл русификатора отсутствует | Работа без русификатора, озвучка по имени файла |
| Реплика не найдена в русификаторе | Пропуск озвучки, запись в лог |
| Аудиофайл не найден | Пропуск воспроизведения, запись в лог |
| Неправильный формат имени файла | Файл пропускается установщиком |
| Шина "Voice" не создана | Использование шины "Master" по умолчанию |

#### 8.2. Логирование

Система выводит сообщения в консоль:
```
[VoiceManager] Инициализирован. Папка: res://voice_mod/audio/
[VoiceManager] Русификатор загружен. Строк: 15114
[DialogueVoice] Найдена реплика в русификаторе для ID: F6mK5ZQ0
[VoiceManager] Воспроизводится: u_tebya_kruzhitsya_golova.flac
[DialogueVoice] Нет озвучки для реплики: Какая-то реплика
```

### 9. Конфигурация

#### 9.1. Параметры voice_settings.ini

**Раздел [general]:**
- `enabled` (bool) — включение озвучки
- `volume_db` (float) — громкость в децибелах
- `cache_enabled` (bool) — кэширование аудио
- `use_rusifier` (bool) — использование русификатора

**Раздел [behavior]:**
- `playback_mode` (string) — режим воспроизведения (queue/immediate/wait)
- `on_click_behavior` (string) — поведение при клике (stop/wait/ignore)

**Раздел [debug]:**
- `log_enabled` (bool) — логирование в консоль
