# INSTALLATION GUIDE - RPG Maker MV

## Быстрая установка

### 1. Скопируйте файлы плагинов

Переместите файлы из папки `js/plugins/` в ваш проект:

```
Ваш_Проект/
└── js/
    └── plugins/
        ├── VoiceMod.js      ← основной плагин (обязательно)
        └── VoiceAuto.js     ← авто-озвучка (опционально)
```

### 2. Включите плагины в редакторе

1. Откройте ваш проект в **RPG Maker MV**
2. Нажмите `F10` или перейдите в `Tools` → `Plugin Manager`
3. Добавьте новый плагин:
   - Нажмите кнопку "New Plugin"
   - Выберите файл `VoiceMod.js`
   - Установите значение **ON**

4. (Опционально) Добавьте второй плагин для авто-озвучки:
   - Нажмите "New Plugin"
   - Выберите файл `VoiceAuto.js`
   - Установите значение **ON**
   - **Важно:** Убедитесь что `VoiceAuto.js` стоит **ПОСЛЕ** `VoiceMod.js` в списке!

### 3. Настройте параметры VoiceMod

Выделите плагин `VoiceMod` в списке и настройте:

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| VoiceFolder | `audio/voice` | Папка с аудиофайлами |
| RusifierPath | `data/Русский.cld` | Путь к файлу русификатора |
| DefaultVolume | `100` | Громкость (0-100) |
| PlaybackMode | `queue` | Режим: queue/immediate/wait |

### 4. Создайте структуру папок

Создайте папку для аудиофайлов в вашем проекте:

```
Ваш_Проект/
├── audio/
│   └── voice/          ← создайте эту папку
├── data/
│   └── Русский.cld     ← опционально
└── js/
    └── plugins/
        ├── VoiceMod.js
        └── VoiceAuto.js
```

### 5. Добавьте аудиофайлы

Поместите ваши файлы озвучки в папку `audio/voice/`:

```
audio/voice/
├── andy_hello.ogg
├── leyley_greeting.ogg
├── u_tebya_kruzhitsya_golova.ogg
└── ...
```

**Форматы:** OGG (рекомендуется), MP3, WAV, WebM, M4A

### 6. Добавьте русификатор (опционально)

Если хотите использовать автоматическую генерацию имен файлов из русских реплик:

1. Найдите файл `Русский.cld` в вашей игре (обычно в `www/data/` или `www/languages/`)
2. Скопируйте его в папку `data/` вашего проекта

## Проверка работы

### Тест через событие

1. Создайте новое событие в любом месте карты
2. Добавьте команду:
   ```
   ◆Show Text：Энди
   ：    ：Привет! Это тест озвучки.
   ```
3. После команды показа текста добавьте:
   ```
   ◆Script：VoiceManager.playVoiceForText("Привет! Это тест озвучки.", "Энди");
   ```
4. Запустите игру (F9) и активируйте событие

### Тест через Plugin Command

Добавьте в событие:
```
◆Plugin Command：PlayVoice andy_hello
```

Или для реплики по ID:
```
◆Plugin Command：PlayVoiceForLine F6mK5ZQ0 Энди
```

## Интеграция с существующим проектом

### Если используете стандартные диалоги

Плагин `VoiceAuto.js` автоматически добавит озвучку ко всем диалогам. Просто включите его.

### Если используете плагины визуальных новелл

Для плагинов типа Yanfly Message Core, MOG Message и других:

1. Отключите `VoiceAuto.js`
2. Используйте ручные вызовы в событиях или
3. Создайте интеграцию через API плагина ВН

Пример для кастомной системы:
```javascript
// В отдельном плагине после VoiceMod.js
MyVN.onShowText = function(text, speaker) {
    VoiceManager.playVoiceForText(text, speaker);
};
```

## Отладка

### Консоль браузера

1. Запустите игру в браузере
2. Нажмите F12 для открытия консоли
3. Ищите сообщения:
   ```
   [VoiceManager] Инициализирован. Папка: audio/voice
   [VoiceManager] Русификатор загружен. Строк: 15114
   [VoiceManager] Воспроизводится: andy_hello.ogg
   ```

### Частые ошибки

**Ошибка: VoiceManager не найден**
- Убедитесь что VoiceMod.js включен в Plugin Manager
- Проверьте что плагин стоит перед другими плагинами озвучки

**Ошибка: Файл не найден**
- Проверьте путь к файлу в параметре VoiceFolder
- Убедитесь что файл существует в папке audio/voice/
- Проверьте расширение файла (.ogg, .mp3 и т.д.)

**Ошибка: Русификатор не загружен**
- Проверьте что файл `Русский.cld` находится в папке `data/`
- Убедитесь что параметр RusifierPath указан правильно
- Проверьте консоль на ошибки парсинга JSON

## Публикация игры

При сборке проекта (`File` → `Deployment`):

1. Убедитесь что папка `audio/voice/` включена в сборку
2. Файл `Русский.cld` должен быть в папке `data/`
3. Плагины должны быть в `js/plugins/`

Для мобильной версии:
- Аудио будет автоматически сконвертировано при сборке
- Помните что на мобильных устройствах автовоспроизведение звука требует взаимодействия пользователя
