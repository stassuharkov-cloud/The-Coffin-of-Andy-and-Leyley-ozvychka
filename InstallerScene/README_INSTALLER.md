# Инструкция по установке озвучки

## Быстрый старт

1. **Скопируйте файлы озвучки** (огромный файл/файлы от блогера) в корень папки с проектом (рядом с `project.godot`).
   - Формат имен файлов должен быть: `ID_Персонаж.ext` или `Персонаж_ID.ext`
   - Примеры: `F6mK5ZQ0_andy.flac`, `line123_betty.ogg`

2. **Запустите сцену установщика**:
   - Откройте `InstallerScene/Installer.tscn` в Godot
   - Нажмите F5 (Run Scene)
   - Дождитесь завершения установки

3. **После установки**:
   - Все файлы будут распределены по папкам: `voice_mod/audio/<персонаж>/`
   - Можно удалить исходные большие файлы из корня проекта
   - Запустите основную игру — кэш таймкодов создастся автоматически при первом запуске

## Как это работает

### Установщик (`VoiceInstaller.gd`)
- Сканирует весь проект в поисках аудиофайлов (.flac, .ogg, .wav, .mp3)
- Пропускает папку `voice_mod/` (туда уже установленные файлы)
- Парсит имя файла, определяя персонажа и ID реплики
- Копирует файлы в структуру: `voice_mod/audio/<имя_персонажа>/<id>.ext`
- Показывает прогресс на экране

### Система таймкодов
При первом запуске игры после установки:
- `VoiceTimingManager` автоматически сканирует `voice_mod/audio/`
- Измеряет длительность каждого аудиофайла
- Сохраняет результаты в `user://voice_timing_cache.json`
- Последующие запуски используют кэш (мгновенная загрузка)

## Структура после установки

```
project/
├── project.godot
├── voice_mod/
│   └── audio/
│       ├── andy/
│       │   ├── F6mK5ZQ0.flac
│       │   └── line456.flac
│       ├── betty/
│       │   └── abc123.ogg
│       └── ...
└── InstallerScene/
    └── Installer.tscn
```

## Примечания

- Если имена файлов не содержат подчеркивания `_`, они будут пропущены
- Имена персонажей приводятся к нижнему регистру и очищаются (пробелы → `_`)
- При повторном запуске установщика существующие файлы не перезаписываются
- Для принудительного пересоздания кэша таймкодов удалите `user://voice_timing_cache.json`
