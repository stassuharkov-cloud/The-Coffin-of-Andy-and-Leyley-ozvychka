## Альтернативный формат - по ID диалога

Если вы используете русификатор с ключами:

```

ch1_intro_001_andy.flac
ch1_intro_002_leyley.flac
ch1_kitchen_015_andy.flac
ch1_kitchen_016_leyley.flac
ch2_basement_042_andy.flac

ch3_final_100_andy.flac

```

## Советы

1. **Используйте нижний регистр** - `andy_privet.flac` а не `Andy_Privet.flac`
2. **Транслитерация** - используйте латиницу для совместимости
3. **Без спецсимволов** - только буквы, цифры и подчеркивания
4. **Короткие имена** - легче управлять и искать
5. **Единый стиль** - выберите один формат и придерживайтесь его

## Поддерживаемые расширения

- `.flac` - рекомендуется (лучшее качество без потерь)
- `.ogg` - хорошее сжатие
- `.wav` - без сжатия (больший размер)
- `.mp3` - максимальное сжатие
